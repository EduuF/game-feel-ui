Install & Use game-feel-ui in 60 Seconds

Follow this step-by-step guide to connect the 39 Game Feel mechanics, Coyote Time UX patterns, and 0 KB Web Audio engine to your AI coding assistant.

01

Choose Your Installation Method

You only need one of the three methods below depending on which AI coding tool you use.

RECOMMENDED · ALL AGENTS

Universal Skills CLI (npx)

Works automatically with Claude Code, Cursor, Windsurf, Codex, and Gemini CLI. Run inside your project root:

npx skills add e-fiuza/game-feel-ui
CLAUDE CODE MARKETPLACE

Claude Code Plugin

If you use Claude Code's native plugin manager, run these two slash commands directly inside your Claude session:

/plugin marketplace add e-fiuza/game-feel-ui
/plugin install game-feel-ui
MANUAL GIT CLONE

Global ~/.claude Folder

Clone directly into your global skills directory so every repository on your machine has access to game-feel-ui:

git clone https://github.com/e-fiuza/game-feel-ui.git ~/.claude/skills/game-feel-ui

04

Frequently Asked Questions

Does this add MP3/WAV files or heavy npm packages?

No. Every sound effect is synthesized in real time via the browser's native Web Audio API (0 KB of external audio assets), and animations prioritize compositor-safe CSS transform and opacity.

Is it safe for enterprise/B2B SaaS apps?

Yes. The skill calibrates intensity by product archetype—subtle scale(0.97) + 160ms Coyote Time for B2B SaaS, and more expressive spring overshoot for consumer or gaming apps.

What about users with motion sensitivity?

Every code pattern generated by game-feel-ui enforces @media (prefers-reduced-motion: reduce), collapsing spatial motion to clean opacity fades while preserving UX forgiveness.

Which frontend stacks are supported?

All 11 major stacks: React, Next.js, Framer Motion, Tailwind CSS, Vanilla CSS/JS, Vue 3, Svelte, Angular, SwiftUI, React Native, and Flutter.
