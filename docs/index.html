What changes when you install `game-feel-ui`?

Why asking a vanilla LLM to "add nice animations" falls short—and how this skill fixes it deterministically.

WITHOUT SKILL · VANILLA CLAUDE / CURSOR

Generic CSS Transitions

  • ✗ Slaps transition: all 0.3s ease-in-out onto buttons, causing sluggish input latency.
  • ✗ Uses blocking window.confirm() or heavy modals for destructive actions.
  • ✗ Zero awareness of Coyote Time (dropdowns close the millisecond the cursor slips).
  • ✗ Cannot synthesize zero-asset Web Audio feedback or calibrate intensity for B2B vs. Consumer apps.
WITH SKILL · npx skills add EduuF/game-feel-ui

Deterministic Game-Feel Engineering

  • ✓ Runs --audit across your codebase to compute a 0–100 Juice Score and pinpoint dead interactions by file and line.
  • ✓ Applies 12 deterministic context rules (Hold-to-Commit on deletes, Pitch Escalation on checklists, 160ms Coyote grace on menus).
  • ✓ Calibrates CSS tokens via --juice, --forgiveness, and --audio dials so B2B SaaS stays crisp and non-fatiguing.
  • ✓ Enforces 60fps compositor-only animations (transform, opacity) and prefers-reduced-motion fallbacks.
