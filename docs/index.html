🧠 Como a Skill Funciona no Claude Code

Ao invés de despejar textos gigantes no prompt, a game-feel-ui usa busca indexada BM25, um contrato determinístico de regras de contexto (reasoning_contract.py) e um scanner estático de código (audit.py).

PASSO 1 — AUDITORIA AUTOMÁTICA

Scanner de Codebase (--audit)

Inspeciona seus arquivos .tsx, .vue, .svelte e .css, calcula o Juice Score (0–100), detecta anti-padrões (como transition-all ou falta de Coyote Time) e aponta arquivo:linha exatos.

PASSO 2 — BLUEPRINT & DIALS

Gerador de Blueprint (--blueprint)

Cruza o tipo do seu produto (SaaS, Fintech, E-commerce, AI Chat, EdTech) com 3 Dials ajustáveis de 1 a 10 (--juice, --forgiveness, --audio) e gera os tokens CSS globais.

PASSO 3 — RECEITAS EM 5 CAMADAS

Domínios & 11 Stacks (--domain / --stack)

Entrega código idiomático para React 19, Next.js, Framer Motion, Tailwind, GSAP, shadcn/ui, Vue, Svelte, React Native e Flutter com fallback obrigatório para prefers-reduced-motion.

🚀 Como Instalar e Usar

1. Instalar no Claude Code (Global ou no Projeto)
# Clonar direto nas skills globais do Claude Code
git clone https://github.com/SEU-USUARIO/game-feel-ui.git ~/.claude/skills/game-feel-ui

# Ou via CLI de plugins do Claude Code
/plugin marketplace add SEU-USUARIO/game-feel-ui
2. Comandos Principais do Motor
# Auditar uma aplicação existente
python scripts/search.py --audit "./src"

# Gerar Blueprint com Dials
python scripts/search.py "saas kanban" --blueprint --juice 6 --forgiveness 8

# Buscar mecânica ou componente específico
python scripts/search.py "hitstop freeze frame" --domain mechanics
