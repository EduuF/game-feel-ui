EXPERIMENTO #01 • HERO ACTION

1. Hitstop (Freeze Frames) + Antecipação + Partículas

Nos jogos: Congelar 4 frames quando um golpe acerta dá peso físico ao impacto.
Na Web UI: Ao clicar no botão do Lado B, ele comprime (scale(0.92)), congela por 85ms para criar tensão cinestésica e explode com mola + faíscas + acorde musical. 

// Mecânica: hitstop-micro-pause + particle-micro-burst

await new Promise(r => setTimeout(r, 85)); // 2. Hitstop (85ms Freeze Frame)
spawnSparks(btn); playHeroChime(); // 3. Impacto + Recompensa
btn.style.transform = 'scale(1)'; // 4. Spring Overshoot

Arquitetura da Skill game-feel-ui

Projetada nos moldes da ui-ux-pro-max, ela combina busca local indexada por BM25, contrato determinístico de regras de contexto e auditoria estática de código:

01 • AUDITOR DE CODEBASE (--audit)

Detecta onde falta Game Feel

O script scripts/audit.py varre seus arquivos .tsx, .vue, .svelte e .css, calcula um Juice Score (0–100) e aponta exatamente o arquivo:linha de botões secos, menus sem Coyote Time, contadores sem tabular-nums e animações que travam a thread.

02 • RACIOCÍNIO DETERMINÍSTICO

12 Regras de Contexto

O módulo reasoning_contract.py detecta se sua tela possui Kanban, Checkout, Streaming de IA, Ações Destrutivas ou Formulários OTP, selecionando automaticamente as mecânicas certas sem risco de "efeito caça-níquel".

03 • 11 STACKS & ACESSIBILIDADE

60/120fps + Reduced Motion

Guias dedicados para React 19 (useOptimistic), Next.js, Framer Motion (whileTap, layoutId), Tailwind, CSS WAAPI, GSAP, shadcn/ui, Vue, Svelte, React Native e Flutter — sempre respeitando prefers-reduced-motion.
